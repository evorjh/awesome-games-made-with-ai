An incremental space factory where you place machines in orbit around a newborn star and time reactor pulses for bonus Stardust.

## Play notes

You start in Cinder Orbit with one Extractor circling a glowing young star, earning Stardust every second, and spend it on new orbit slots, more machines and shared upgrades for each machine type. A capacitor charges between pulses, and pressing Space inside its golden window gives a Perfect pulse that builds a combo. A researcher called LYRA and an engineer called TOOLS walk you through each new system. The page describes four sectors, Reforge resets for permanent Star Core upgrades and an Open Orbit mode after the campaign, and the creator says the code was AI-generated with some translations also done by AI. The page calls this a free browser demo of a game coming to Steam. Best on a computer: the page says phones are not supported yet.

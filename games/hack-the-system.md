## Prompt

```text
I want to make a scary hacking game that gives AI vibes. And it would be even more fun if you can hide some of the features for me so you can surprise me when I playtest it. I didn't add any art assets, so you will have to get creative with those. I imagine a text heavy game that has scary effects and animations to give that hacker vibe sort of like the matrix. I don't want the game to be complicated but add scary elements and unexpected game behavior. The main goal of the game will be to hack "The System" So completing that will be the end of the game. Any ideas if you can make this work?
```

This is part of the prompt; the creator didn't share all of it.

- **Made with:** Claude Opus 5.5, Claude Fable 5, Claude Code
- **Where they name the AI:** [“The first versions were built back in July using Claude Fable 5. It got me to a workable 2D Command &amp; Conquer-style game, but it wasn’t great to play. I prompted Opus 5.5 to “Make it a LOT more fun” and then later to “Port this game to three.js” and the game was transformed.”](https://simonwillison.net/2026/Oct/28/vibe-game-development/#battle-drones)
- **Creator:** [@simonw](https://x.com/simonw)
- **Genre:** Strategy
- **Plays on:** Computer and phone
- **Price:** Free
- **Controls:** Click or tap to select units and send them; use the Base panel to build
- **Likes on the original post:** Unknown

A real-time strategy game where robot armies mine scrap, build bases and fight for territory, with skirmishes, a daily op, waves to survive and random maps.

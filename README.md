## How to use a prompt

Some creators share the prompt they used. Their games have a **Prompt** link instead of **Details**.

1. Open the game's page and copy the block under **Prompt**.
2. Paste it into the AI the game was made with, or any AI that writes code.
3. Ask for a single HTML file you can open in your browser, then keep asking for changes.

Some creators shared only part of their prompt; their pages say so.
